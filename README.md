# N5 Flashcards App 🎴

Ứng dụng học từ vựng JLPT N5 (Minna no Nihongo) theo phong cách lật thẻ Tinder (quẹt phải để học thuộc, quẹt trái để học lại).

Được xây dựng bằng ReactJS, Vite và Framer Motion. 

## ✨ Tính năng chính

- **2 Chế độ học đa năng**: 
  - *Từ vựng*: Mặt trước (Kanji + Hiragana) -> Chạm lật ra sau để xem nghĩa Tiếng Việt.
  - *Kanji*: Mặt trước (Kanji) -> Chạm lật ra sau để xem Hiragana và nghĩa Tiếng Việt.
- **Thao tác lật thẻ 3D** mượt mà, cảm giác lật như cầm Flashcard thật.
- **Tuỳ chọn linh hoạt**: Chọn bài cần học (Lesson 1-25) và cài đặt hẹn giờ học (1-60 phút).
- **Phản hồi hoạt hình (Animations)**: Chỉ báo vuốt trái (Chưa thuộc), vuốt phải (Đã thuộc) rõ ràng với lò xo đàn hồi cực nhanh.

## 🚀 Cách sử dụng trên Máy tính (Desktop/Laptop)

Rất đơn giản, bạn chỉ cần làm 2 bước:

1. **Cài đặt Node.js**: Truy cập [https://nodejs.org](https://nodejs.org), tải và cài đặt bản **LTS (Recommended For Most Users)**.
2. **Khởi chạy Ứng dụng**: 
   - Mở thư mục code này.
   - Click đúp vào file **`run_app.bat`**.
   - Chờ một vài giây, phần mềm sẽ tự chạy và mở tự động trên trình duyệt web của bạn.

## 📱 Cách lấy ứng dụng cho Điện thoại Android

Hệ thống đã được thiết lập để tự động dịch ra file cài `.apk` mỗi khi có thay đổi trên GitHub.

1. Vào tab **Actions** trên GitHub.
2. Bấm vào tiến trình thành công (tích xanh ✅) trên cùng.
3. Cuộn xuống phần **Artifacts** ở dưới cùng.
4. Tải file nén `N5-Flashcards-App` về, giải nén ra sẽ được file `app-debug.apk` để copy vào điện thoại và cài đặt.

*(Gợi ý: Cách nhanh nhất không cần file cài là mở link qua điện thoại trên chung 1 mạng WiFi, sau đó chọn tính năng "Thêm vào màn hình chính" (Add to Home Screen) trên trình duyệt để sử dụng như 1 App xịn).*
